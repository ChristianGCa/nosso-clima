# Weather UI contrast evidence — 2026-10-01

The production web build was checked with `npm run test:a11y` in Playwright Chromium at 360 × 800 and 1280 × 800. API responses were local fixtures, with no live Open-Meteo request. The browser test loaded each of the ten bundled WebP backgrounds separately, scanned each rendered state with axe, and checked visible text and the search field's border and focus outline against their computed surfaces. The neutral state was scanned at both viewport sizes.

`apps/web/test/contrast.mjs` reads every pixel of the active bundled image and its rendered CSS background layers. It uses the darkest and brightest channel bounds across that image to calculate a conservative lower bound for each contrast ratio. Because those bounds may combine channels from different pixels, the reported value can be lower than the ratio at any one visible pixel. Text size and weight come from computed styles; ordinary text must reach 4.5:1, large text and control boundaries 3:1. The script fails the gate when a lower bound misses its threshold.
